# pages.md

Tài liệu cấu trúc các trang giao diện (Pages) của hệ thống Universe Manager GUI.

- **Tên Page**: `DashboardPage`
- **Mô tả**: Trang tổng quan hiển thị các thẻ thống kê tổng số ứng dụng quản lý, ứng dụng tùy chỉnh, đường dẫn thư mục quản lý hiện hành và bảng danh sách ứng dụng.

- **Tên Page**: `ConfigPage`
- **Mô tả**: Trang cấu hình ứng dụng cho phép chọn thư mục quản lý (thông qua picker của Tauri) và lưu cấu hình nguyên tử xuống backend an toàn.

- **Tên Page**: `ScanPage`
- **Mô tả**: Trang quét danh mục ứng dụng từ thư mục quản lý hoặc chọn thư mục nguồn để phân tích phát hiện các thành phần ứng dụng mới.

- **Tên Page**: `AppManagerPage`
- **Mô tả**: Trang quản lý vận hành ứng dụng, cho phép gửi lệnh khởi động hoặc dừng các tiến trình ứng dụng thông qua kênh IPC an toàn kèm xác thực hành động.

- **Tên Page**: `SearchPage`
- **Mô tả**: Trang tra cứu và tìm kiếm nhanh ứng dụng trong thư mục quản lý theo tên hoặc từ khóa, hiển thị bảng kết quả kèm nguồn ứng dụng.

- **Tên Page**: `SettingsPage`
- **Mô tả**: Trang cài đặt hệ thống cho phép thay đổi ngôn ngữ (Tiếng Việt / English), chủ đề giao diện (Hệ thống / Sáng / Tối) và cấu hình phông chữ hiển thị.
