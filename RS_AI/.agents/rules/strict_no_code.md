# Strict Workflow Rule

- **No Coding Allowed**: Agent tuyệt đối không được phép viết code, sửa đổi mã nguồn (source code) hay thay đổi trực tiếp bất kỳ tính năng nào trong dự án, trừ khi có lệnh cực kỳ đặc biệt ghi đè rule này.
- **Only Plan and Markdown**: Mọi yêu cầu thay đổi, cải tiến hay phân tích (ví dụ: refactor UI, đổi cơ chế tính năng) chỉ được phép ghi nhận lại, lên kế hoạch (plan) và tạo checklist công việc vào các file Markdown (`.md`) trong các thư mục `TODO` hoặc các file kế hoạch dự án.
